README - PROYECTO DE DESARROLLO WEB - CODERHOUSE 

DESCRIPCION
Este proyecto consiste en el desarrollo de una pagina orientada en la capacitacion de calzado
para vendedores, en la cual abarca las 3 marcas principales y/o mas conocidas en el ambito
de los deportes.


TECNOLOGIAS UTILIZADAS 
- HTML5
- CSS3
- SASS/SCSS
- GIT
- GITHUB 
- Y UN POCO DE JS

- STYLES
 
SASS 
Para compilar los archivos sass utilizé:

sass --watch sass/main.scss styles/styles.css

Este comando permite observar los cambios realizados en los archivos
SCSS y actualizar automáticamente el archivo CSS.
